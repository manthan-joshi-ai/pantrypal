What We Learnt

What we learnt building with AI

We used Claude Code as our AI pair programmer throughout this hackathon. Here's what we genuinely took away — the good and the honest.

✅ What worked really well
⚡
AI as an efficiency multiplier We built a full-stack app — backend, frontend, dark/light theme, 6 features — in a single day. That's not possible without AI assistance.
🧹
Boilerplate disappears instantly Setup, config, repetitive code, CSS structure — AI handled all of it. We spent our time on the actual problem, not plumbing.
🎯
Focus shifts to problem solving Coding is only 15–20% of solving a real problem. The rest is understanding the user, defining the right question, and making design decisions. AI takes care of the 15% — so you invest your energy in the 85% that actually creates value.
✂️
Brilliant for small, well-defined tasks "Add a serving size adjuster that scales nutrition values" — gave us working code in seconds. Clear task, clear output.
⚠️ Watch-outs — being honest
💸
Cost is a real overhead Every API call to Claude has a price. For a free consumer tool, this needs careful thought — free tier or subscription pricing would be needed at scale.
🌀
AI Hallucinates When we switched our AI assistant from an OpenAI key to the AWS Bedrock key mid-build, it started suggesting incorrect code and confidently referencing APIs that didn't exist. Same question, different model — completely different reliability. AI doesn't flag when it's guessing.
🧭
Easy to drift from the goal AI suggestions can pull you toward interesting features that aren't core. We had to consciously ask "does this solve the original problem?" to stay on track.
🧩
Struggles with complex, ambiguous problems AI excels at clear tasks. When requirements were vague or multi-layered, output quality dropped. Human judgement is still essential for architecture decisions.

How we built it — with prompts

PantryPal was built using Claude Code as an AI pair programmer. Here are the key prompts that shaped the product.

"
We are participating in a hackathon on AI ideas. We plan to build a webapp for food/dish recommendations — recommend a dish which we can prepare from the leftover food items at home. Name of the assistant is PantryPal.
"
Build something eye-catching UI. It will take the list of ingredients from the user and return a healthy recipe. It will also take user health conditions data and suggest recipes based on it.
"
Let's add: Save/favourite recipes, Shopping list, Serving size adjuster, and Cooking mode — full-screen step-by-step view with a progress bar that keeps the screen awake during cooking.
"
All together a new UI as per the current market trends for a food app — with dark/light theme toggle.
"
Let's migrate from AWS Bedrock / MiniMax to Anthropic Claude API — use claude-sonnet-4-6 as the model.
"
I want to add a feature where user can have a chef chat for every recipe. Also add food photo upload — user should be able to upload a fridge or pantry photo and the AI should detect the ingredients with an editable review step.
