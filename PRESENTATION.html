What We Learned

Real lessons from a real build 🧠

1
AI model availability matters Not all Bedrock models are accessible — we discovered MiniMax M2 as the optimal model through live testing during the hackathon.
2
Prompt engineering is half the product Structuring the health profile into the prompt context was critical to getting accurate, safe recipe suggestions.
3
AI responses need defensive parsing MiniMax returns <reasoning> blocks before JSON — we had to strip them. Always validate and sanitize AI output.
4
Speed of AI-assisted development Using Claude Code as a pair programmer, we went from zero to a fully featured app with dark/light theme in under a day.
5
UX is what judges remember Features like cooking mode and serving adjuster took 30 minutes to build but dramatically elevated the demo impact.
6
CSS architecture scales fast A proper design system with CSS variables enabled instant dark/light theming across the entire app.

How we built it — with prompts

PantryPal was built using Claude Code as an AI pair programmer. Here are the key prompts that shaped the product.

"
We are participating in a hackathon on AI ideas. We plan to build a webapp for food/dish recommendations — recommend a dish which we can prepare from the leftover food items at home. Name of the assistant is PantryPal.
"
Build something eye-catching UI. It will take the list of ingredients from the user and return a healthy recipe. It will also take user health conditions data and suggest recipes based on it.
"
Let's add: Save/favourite recipes, Shopping list, Serving size adjuster, and Cooking mode — full-screen step-by-step view with a progress bar that keeps the screen awake during cooking.
"
All together a new UI as per the current market trends for a food app — with dark/light theme toggle.
